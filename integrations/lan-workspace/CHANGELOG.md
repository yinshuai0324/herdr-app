# 多点终端更新日志

## [0.1.27] - 2026-11-27

### 修复
- 统一系统菜单、命令面板和开始菜单里的布局名称。Windows98 的启动画面和相关弹窗也显示新名称。

## [0.1.26] - 2026-11-27

### 修复
- 修复更新日志弹窗的背景在圆角处露出直角的问题。

## [0.1.25] - 2026-11-27

### 修复
- 设置中的三种布局现在显示为「亮色」「深色」和「Windows98」。

## [0.1.24] - 2026-11-27

### 新功能
- **查看多点终端的版本记录** 弹窗集中展示多点终端自己的中文更新日志。

### 修复
- 修复点击「查看更新日志」跳回设置的问题。更新提醒和设置中的入口都会打开日志弹窗。

## [0.1.23] - 2026-11-27

### 新功能
- **自动签名发布** 多点终端通过 GitHub Actions 构建和发布，应用内可以接收更新。

## [0.1.22] - 2026-11-27

### 新功能
- **公司内部登录** 添加主机时可以共享本机项目目录，并在远端工作区中直接打开该目录。
- **记住 SSH 密码** 可以通过 Mac 钥匙串保存密码，以便下次连接时自动使用。
- **简体中文界面** 工作区、主机设置和终端菜单等界面已汉化。
- **应用内更新** 多点终端从自己的 GitHub 发布页下载并验证更新。
